# 🚗 Car Sales Analysis Dashboard (Power BI)

## 📌 Project Overview
This project presents an **interactive Power BI dashboard** designed to analyze and visualize car sales performance across multiple dimensions such as **time, region, brand, body style, dealer, and customer behavior**.

The dashboard supports both **high-level business monitoring** and **detailed transactional analysis**, enabling data-driven insights through intuitive visual storytelling.

---

## 🎯 Objectives
- Analyze **Year-to-Date (YTD)** and **Month-to-Date (MTD)** sales performance  
- Identify trends in **sales revenue, average price, and units sold**  
- Compare performance across **brands, body styles, colors, and regions**  
- Enable **interactive exploration** using filters and drill-down views  

---

## 🧰 Tools & Technologies
- **Power BI Desktop**
- **DAX** (Calculated Measures & KPIs)
- **Data Modeling**
- **Interactive Visual Analytics**

---

## 📊 Dashboard Structure

The report consists of **two well-defined pages**, each serving a distinct analytical purpose.

---

## 🟣 Overview Dashboard (Main Dashboard)

![Overview Dashboard](screenshot/overview-dashboard.png)

### Purpose
Provides a **high-level summary** of overall car sales performance for quick evaluation and trend identification.

### Key KPIs
- **YTD Total Sales**
- **YTD Average Sales Price**
- **YTD Cars Sold**
- Growth percentages and MTD comparisons

### Visual Insights
- Weekly Sales Trend (YTD)
- Sales Distribution by Body Style
- Sales Distribution by Color
- Dealer Region Sales Map
- Company-wise Sales Performance Table

### Interactive Filters
- Body Style  
- Dealer Name  
- Engine Type  

---

## 🟣 Sales Details Dashboard

![Sales Details](screenshot/sales-details.png)

### Purpose
Enables **record-level analysis** to explore the underlying data behind aggregated KPIs.

### Features
- Transaction-level table with:
  - Car ID  
  - Date  
  - Customer Name  
  - Dealer Name  
  - Company  
  - Color  
  - Model  
  - Total Sales Value  
- Conditional formatting for quick comparison
- Scrollable and filter-responsive layout

---

## 🔍 Analytical Highlights
- Clear separation between **summary** and **detailed** analysis  
- Consistent KPIs across pages for interpretability  
- Clean, professional dashboard layout with strong visual hierarchy  
- Design optimized for **business intelligence storytelling**
